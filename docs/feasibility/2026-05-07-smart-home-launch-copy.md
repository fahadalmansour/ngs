- [x] Tone is warm + curated, not technical-spec-driven — every long copy leads with a sentiment ("the brain that runs your smart home", "small piece, large insurance policy"), then quality cues, then specs in bullet form
- [x] Quality / sourcing / local-delivery cues present — every product mentions Riyadh shipping window, warranty, and brand-authentic sourcing
- [x] Both EN and AR provided — bilingual throughout
- [x] SAR currency (`SAR` in EN, `ر.س` in AR), Riyadh-context references — no Western shipping cliché
- [x] No hard-sell hype — uses "we like it" / "ليش نوصي فيه" framing instead of "best-in-class!" / "buy now!"
- [x] No staging — copy is one deploy from live; user pastes into WP admin, no PHP touch needed
- [x] RTL-safe — Arabic blocks marked with `> **bold**` use bidi-friendly punctuation; no LTR-only tricks; price + product names that are Latin-character (UniFi, Aqara, Sonoff) embed naturally inside RTL paragraphs per Arabic web-typography norms
- [x] Master catalogue is the source of truth — pricing pulled directly from `Regular Price (SAR)` + `Sale Price (SAR)` columns; AR titles improve on the existing machine-translated `Product Name (AR)` values without conflicting

## Apply guide

1. WP admin → **Pages** → edit Smart Home & IoT category-archive description (or use a category-page block) → paste § 1 EN/AR.
2. WP admin → **Products** → for each of the 5 SKUs:
   - Replace `Product Name (AR)` with the AR title from this doc (drop "ساحر"-style mistranslations)
   - Replace EN long description with the § long EN block
   - Add the AR long block to the Arabic-description meta field (`_ng_ar_description` if your theme uses that key, else use a bilingual ACF if installed)
   - Set the Yoast/Rank Math title + meta from the SEO summary table
3. After WP-admin saves, the **woocommerce_ready_import.csv** in repo will fall out of sync — round-trip these descriptions back through the master xlsx on the next catalog cycle (per `marketing-neogen` skill rule).
